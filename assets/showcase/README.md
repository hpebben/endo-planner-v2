# Teaser stage screenshots

These four 1280 × 800 WebP images show actual EndoPlanner interface panels,
captured in Chromium from the v1.6.182 application with the licensed Kobenhavn CS
heading font loaded. Panels are arranged to fit
the teaser preview; the running application's layout is responsive.

The fictional example uses Fontaine IV, WIfI W2 I2 fI1, a hallux/first-ray wound,
and a left SFA stenosis measured at 5 cm with heavy calcification. Its selected
route continues through the anterior tibial artery, dorsalis pedis and first
dorsal metatarsal artery. The crossing/treatment selections are example entries.
No patient data is included. The teaser labels the images “Example case.”

1. Fontaine, WIfI and wound location controls.
2. Disease map, lesion extent, target path and selected woundosome views.
3. Plan at a glance, shared route support, crossing and treatment devices.
4. Illustrated clinical and disease summary cards.
